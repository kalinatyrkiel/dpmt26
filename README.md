# Prompty i nie tylko

Kopia prelekcji z UX speak in 2026, na meetup Design Practice × Mobile Trends (30 listopada 2026, Hevre, Kraków).

Wygląd: czarne tło, limonka i ciepły beż jak na [affinity.studio](https://www.affinity.studio/). Nagłówki: Fraunces (zamiennik Affinity Serif). Tekst: Manrope (zamiennik Canva Sans). Krojów Affinity i Canvy nie da się legalnie wkleić do decku.

## Uruchomienie

```bash
npm install
npm run dev
```

Nawigacja: strzałki, spacja lub klik.
